# End-to-End Retail Sales Data Analysis

## Project Overview

This project analyzes supermarket retail sales data to understand sales performance, product categories, customer behavior, city-wise sales, and monthly sales trends.

The project was completed as part of the **Syntecxhub Data Science Internship**.

## Tools Used

* Python
* Pandas
* Matplotlib
* Google Colab

## Dataset

The dataset contains **1,000 supermarket sales records** with **17 columns**, including product line, city, customer type, gender, quantity, total sales, payment method, and date.

## Data Cleaning

The following steps were performed:

* Checked for missing values
* Checked for duplicate records
* Converted the Date column into datetime format
* Verified data types

**Data Quality Result:**

* Missing values: 0
* Duplicate rows: 0

## Exploratory Data Analysis

The analysis covered:

* Product line sales
* City-wise sales
* Monthly sales trends
* Customer type sales
* Gender-wise sales

## Key Performance Indicators

* **Total Revenue:** 322,966.75
* **Average Order Value:** 322.97
* **Total Records:** 1,000

## Key Insights

1. **Food and beverages** recorded the highest product-line sales of **56,144.84**.
2. **Naypyitaw** recorded the highest city-wise sales of **110,568.71**.
3. **January 2019** recorded the highest monthly sales of **116,291.87**, while February recorded the lowest.

## Recommendations

* Maintain sufficient stock for high-performing products.
* Study successful sales patterns in Naypyitaw and apply suitable strategies to other cities.
* Use targeted promotions and inventory planning during lower-sales periods.

## Conclusion

This project demonstrates practical skills in data cleaning, exploratory data analysis, KPI calculation, data visualization, and business insight generation using Python and Pandas.
